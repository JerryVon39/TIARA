# TIARA 功能走查

2026-11-09 · 当前 v0.26.0 工作区

计划项已整理到 [功能待办](BACKLOG.md)。

在独立的浏览器会话和临时服务中，从空库走了一遍「本季找番 → 加入在追 → 记一话 → 撤销 → 移出 → 再次加入 → 查看备份」。季度表和进度均为测试数据。桌宠的提醒设置和完结行为依据当前菜单及生成的数据核对，未在真实 SSP 宿主中试跑。

## 走查中实际遇到的问题

| 优先级 | 场景 | 当前体验 | 建议与验收 |
| --- | --- | --- | --- |
| 先做 | 暂停一部番，过几周回来继续 | 测试番已看 3/12，从本周移出后再从本季加入，变成 0/12。面板没有可浏览的暂停或弃追列表。 | 增加暂停、继续与已看完归档。暂停后退出今日提醒，重新加入恢复到 3/12。清除观看记录作为单独操作。 |
| 先做 | 半途加入，或者迁入已有进度 | 加入后默认 0/12，面板只能逐话加减。中途加入还会默认从加入日计待看，用户不能选是否补前面的集数。 | 加入时可填「已看至第 N 话」，并选择从头补或从最新一集开始追。为已有条目提供直接改进度的入口。 |
| 先做 | 第一次打开，想离线添加一部旧番 | 空库默认落在本周。可以从本季缓存加番，但搜索只筛当前列表，网页没有按名称手动建档的入口。季度页提示回本周补时刻，本周卡片却没有时刻编辑入口。 | 空状态直接提供「手动添加」和「从本季选」。同一表单能设番名、已看集数、开播星期与时间。断网也能从空库加第一部番。 |
| 接着做 | 误点一次记账，马上撤销 | 实测快速撤销恢复到 0/12，统计仍显示本周 1 话、累计 1 话、连续 1 天。 | 让撤销同时冲销这次观看记录。当天只有一笔被撤销的记账时，话数和连续天数均不增加。 |
| 接着做 | 想恢复较早的备份 | 对话框列出多份备份，却只有一个恢复按钮，目标总是列表第一份。 | 允许选日期或版本，显示备份时间和差异预览。明确「恢复整库」与「找回一部番」的范围。 |

## 值得验证和补足的能力

| 场景 | 现有能力与缺口 | 推荐先做的范围 |
| --- | --- | --- |
| 停播一周、变更时间或番已完结 | 排期主要按星期重复，节目完结与用户看完缺少独立状态。补完旧番时，用户要同时管理它是否仍应参与排片。 | 增加「跳过本周」「下一次开播」和「停止排片」。节目完结后保留追番进度，补完后归档。 |
| 已开播，但用户现在没空 | 桌宠有开播提醒和记一话按钮，缺少按番静音、稍后提醒和统一的免打扰时段。 | 先做全局免打扰和单番提醒开关。开播时提供「稍后提醒」，让用户看完再记。 |
| 从 Bangumi 搬进长期维护的列表 | 面板的同步预览能看变化，首次导入时没有显式选择「只补资料」还是「同时导入我看到哪儿」。 | 保留现有本地进度为默认。首次导入单独提供进度选项，并预览将改变的条目数。 |

下一轮可以从一个「番剧详情」入口开始，承接手动新增、设定当前集数、编辑排期和暂停或归档。用三条场景验收：断网能添加第一部番，暂停后继续时仍是 3/12，已看完的番能从提醒中退出并在归档里找到。接着补统计撤销与备份选择。
