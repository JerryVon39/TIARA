## 功能清单

- [x] **番剧详情与离线新增。** 从空库断网添加一部旧番，可填写番名、总集数、当前进度和开播时刻。在追条目可以从同一入口修改这些字段。也可以按需查询周播时刻，确认后填入表单。
- [x] **补番起点。** 加入时可以填「已看至第 N 话」，也可以选择从头补或从最新一话开始。待看数量按选择计算。
- [x] **暂停、继续与归档。** 从番剧详情暂停或归档。暂停后退出日程和提醒，继续时恢复原进度与排期。已看完的番剧可在「番库」查看详情或恢复到在追。
- [x] **撤销同时冲销统计。** 撤销当天唯一一笔观看记录后，当天话数、累计与连续天数恢复原值。
- [x] **备份选择与预览。** 恢复前选择日期或版本，查看进度差异。区分恢复整库与找回单部番剧。
- [x] **临时调档与完结。** 支持跳过下一次周播、指定下一次开播和停止排片。节目完结后仍能补番，观看完成后可归档。
- [x] **提醒偏好。** Windows 桌宠支持免打扰时段、单番静音和稍后提醒。
- [x] **首次同步的进度选项。** 选择只同步资料或同时导入进度，确认前预览会改变多少条记录。
