## v0.31.0 · 和 TIARA 一起值日

### 1. 托盘快捷操作

- [x] **重排托盘右键菜单。** 顶部按当前状态显示「显示桌宠」或「隐藏桌宠」，紧接着放「置顶」「普通」「沉底」，再放「我的排片」「记一话」等常用操作。
- [x] **快捷切换窗口层级。** 三档都在菜单第一层，当前档打勾。复用立绘右键菜单的切换逻辑，切换立即生效并记住选择。隐藏时也能选择层级，下次显示时生效。
- [x] **托盘验收。** 实机检查托盘与立绘菜单的选中状态一致，隐藏时切换后能找回桌宠，重启保留层级。在 125% 显示缩放下检查键盘选项和菜单显示。

### 2. 已看完番剧分流

- [x] **区分追平、已看完和已归档。** 追平连载指看完目前播出的集数，继续参加排片和开播提醒。达到已知总集数时自动标为已看完。总集数未知时，可在详情手动标记或取消标记。
- [x] **统一网页和桌宠的筛选。** 已看完的条目进入番库独立分组，退出默认排片、开播提醒和托盘「记一话」。记完最后一集时立即提示，提供归档和撤销。保留进度、观看链接和原排期，归档后可在番库检索。
- [x] **处理撤销与总集数变化。** 对尚未归档、按集数自动判定完成的条目，撤销一话或同步后总集数增加时按最新数据重新判定。手动完成由用户取消，归档由用户恢复。
- [x] **完结验收。** 用 v0.30.0 番库副本验证追平后仍有提醒、最后一集后的分流、撤销、未知总集数手动完成，以及归档后的检索。用 Bangumi 测试响应检查同步增加总集数。

### 3. 好感与陪伴

- [x] **关系阶段。** 沿用 0–100 的好感值，分为初识（0–19）、熟络（20–44）、默契（45–74）和信赖（75–100）。在陪伴手账显示当前阶段、离下一阶段还差多少，以及当天的好感来源。按关系阶段加入不同的问候和互动台词。
- [x] **日常互动计分。** 摸头加 1，抱一下加 3，两项每天合计最多加 3。达到额度后仍可互动并得到台词回应。好感单向累计，日常额度按北京时间换日。
- [x] **陪伴活动。** 从「和她聊聊」选择「喝杯茶」或「一起值日」。喝茶用简短的气泡对话，一起值日复用专注计时。当天首次完成任一活动加 2，两项共用一次奖励。
- [x] **关系剧情。** 熟络解锁《两杯茶》，可选她下次如何招呼你。默契解锁《值日后的十分钟》，剧情选择会影响之后的值日收尾台词。信赖解锁《给会长的便笺》，可在手账中回看留言。每段新剧情首次读完加 3，手账可回看剧情与已选分支。
- [x] **旧档迁移。** 保留 v0.30.0 的好感值和已读剧情，按已有好感开放符合条件的新剧情。通过升级向导迁移新增的剧情选择和奖励记录。
- [x] **养成验收。** 检查跨级解锁、好感封顶、同一天重复互动、北京时间跨日、重启与换机后的奖励去重，以及一起值日期间的安静行为。
