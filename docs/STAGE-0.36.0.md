# TIARA v0.36.0 阶段总结

整理于 2026 年 11 月 16 日。

## 本阶段交付

| 功能 | 可使用的入口 |
| --- | --- |
| 番库组合筛选和保存视图 | 「番库」按状态、年份、自订标签和观看链接筛选。当前筛选及命名视图保存在所用浏览器。 |
| 置顶、笔记与多个观看入口 | 番剧详情 →「整理标签、笔记与观看入口」。最多四个播放地址。首选地址沿用旧版的观看链接字段，网页和桌宠读取同一个入口。含剧透的短评默认折叠。 |
| 接着看、紧凑排片和首页 | 「我的排片」上方可接着看最近观看和置顶的番，也可以在「设置」中把「接着看」设为启动页。 |
| 补记观看与历史 | 番剧详情可按北京时间补记连续集数。「观看历史」按番名、日期、观看方式筛选，可展开来源和进度变化，或导出所选范围。 |
| 提醒与数据恢复 | 番剧详情可查看该番的提醒记录。换机预览列出新增、覆盖、移除和保留的条目，也列出便条、外观与陪伴手账的变化。 |
| 设置、空库引导和诊断 | 底栏「设置」集中导航。空库可直接走追本季、补旧番或离线手动添加。诊断报告可选启动与同步状态，预览后复制。 |

番剧个人资料随番库备份，旧档缺少这些字段时可照常读取。本阶段的补记从当前进度继续，跳集与补缺仍是单独的待办。

## 验收

- 161 项自动测试通过，覆盖旧版迁移、番剧个人资料、首选链接、补记日期、历史导出和撤销。
- Edge 验证了保存视图并刷新、剧透折叠、首选链接、新手入口、紧凑布局、首页选择和脱敏报告预览。
- 在 Windows 用 v0.35.0 的备份副本试恢复，验证便条和原番库保留、桌宠排片读取新首选链接、系统 PATH 无 Node.js 时便携包仍可运行。SSP 包通过 YAYA 加载检查。
