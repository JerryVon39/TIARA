# v0.78.3 整体回归验收

2026-11-22 · 已完成 [v0.74 至 v0.78 待办](BACKLOG.md#后续版本方案)，并在最后一版核对主要使用流程。

## 整体审查修复

- 点「记一话」后立刻刷新会丢掉还在等待合并的进度。离开页面时现在会立即提交待写进度，已排队的写入仍按顺序执行。用 Edge 复现旧行为，再确认修复后可从刷新后的页面撤销。
- 「停止TIARA」曾在网页停止接入、已收到的写入仍在运行时返回成功。现在等桌宠与本地服务退出。用受锁阻塞的真实进度写入核对停止命令等待写完，并校验进度和历史均已保存。
- SSP 案件簿的「摸摸头」缺少返回入口。用 SSP 双击打开案件簿，再实点「摸摸头 → 返回案件簿」。实际运行的 YAYA 模块也验证了全部六项的响应与返回链接。
