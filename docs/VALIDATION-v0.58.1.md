# v0.58.1 验收记录

- **两屏位置。** 在 Windows 扩展桌面上使用实际的 125% 主屏和 150% 副屏，副屏位于主屏左侧。解压最终便携 ZIP，在两屏各留一个位置。把鼠标移到对应屏幕后调用托盘召回，桌宠分别回到该屏已存位置。关闭并重新打开窗口后回到最后使用的副屏。
- **副屏停用。** 桌宠留在副屏时，通过 Windows 显示配置停用副屏，确认启用的显示路径从两条变成一条。召回后主屏立绘完整可见，并使用主屏原先保存的相对坐标。在副屏仍停用时重新打开桌宠也通过。验收结束后核对外接屏模式和主屏 125% 缩放已恢复。
- **只读看板。** 使用便携包内置后台和独立 Edge 配置。从设置打开看板，显示样例排片，窗口放在 150% 副屏。全屏仍在该屏；第一次按 Esc 退出全屏，第二次关闭看板并返回面板。自动化验证看板在初次隐藏打开时仍加载排片，在后台暂停定时刷新。
- **发行与升级。** 196 项自动测试全部通过。本机旧的生成快照保留前一天的日期，CI 将它记为提示。重新打包后核对 SHA-256 和空库。从 v0.58.0 便携包用测试番库升级，确认无系统 Node.js 的 PATH 下能启动网页、写入进度并重启读回。公开 SSP 包在独立 SSP/YAYA 环境安装并实际启动。
