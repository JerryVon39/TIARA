# TIARA v0.59.0 全项目审查与改进计划

审查于 2026 年 11 月 20 日。工程就绪度评估为 **78/100，可用，下一版优先修复数据可靠性**。现有网页主流程和便携版迁移可以运行。季表、撤销、备份和启动自恢复仍有已复现的缺口，值得先于下一轮界面调整解决。

## 审查基线

- 当前工作区标记为 v0.59.0，包含已本机启用的自动转补番修正和新版待办。发布基线另以 `origin/main` 的 `ae1d0ce` 及该提交构建的便携包核对。当前工作区的本地 `master` 基线仍是 v0.25.0。后续以发布分支为基线移植对应改动，可避免把历次未提交内容和个人数据混入发行。
- 检查范围包括网页面板和副屏看板、本机服务、追番与集数、排期和提醒、Bangumi 与封面、Windows 桌宠和托盘、陪伴功能、SSP、个人数据和迁移、CLI、发行及开发文档。
- 当前源码的 CI 通过，199 项测试及 105 个脚本语法检查通过。Edge 走查通过，覆盖桌面、390 像素窄窗、键盘、排片、详情、番库、全局搜索、记账、撤销和网页迁移。用已发布构建复测 v0.58.3 便携包迁移、内置运行时启动以及重启后读取和继续记账。
- 当前 C# 桌宠在隔离目录编译成功，仍有一个未使用字段警告。当前 SSP 公开包通过结构检查，安装描述为 CRLF，快照为空，检查范围内无私人数据路径。
- 专项复现使用独立数据目录和本机模拟上游。涉及页面改造和优先级的建议属于本轮设计判断。真实系统通知送达、近期版本的 SSP 宿主运行、大陆多网络、屏幕阅读器和长时间运行属于后续验收范围。

| P1 | 损坏的待提交记录会阻断启动，并被报成端口占用 | 在独立目录放入截断的进度恢复文件，服务退出 1，没有监听端口，终端显示端口全被占用。网页的备份与恢复也因此无法打开。 [写锁与恢复](../lib/library-lock.mjs#L38) · [启动处理](../server.mjs#L3080) | 识别端口、目录权限、写锁和恢复错误。保全损坏文件和可用备份，提供受限只读状态及明确的恢复入口。测试原始档案仍在、恢复后重启正常。 |
| P2 | 历史局部不可读时，统计会显示为全零 | 测试档案有一条有效观看记录，再让一个归档历史路径不可读，统计返回 200，累计由 1 变 0。 [历史读取](../server.mjs#L1408) · [统计](../server.mjs#L2651) | 标注资料缺失或统计暂不可用。仍可读取的结果单独计数，首页、周报和补番目标共享相同口径。 |
| P2 | 公开便携包的编译工具入口与实际内容不一致 | 成品有 152 个条目，运行所需的两个 EXE 和公开数据白名单符合预期。便携包保留 `pack:portable` 脚本，但打包器被 `_portable` 文件名过滤排除。 [打包规则](../tools/pack_portable.mjs#L65) · [脚本入口](../package.json#L10) | 明确源码开发命令和便携包支持的命令。用解压后的真实文件列表测试每个对用户公开的入口，并把发布范围限制在明确的文件清单。 |

## 每版交付检查

1. 从公开主分支建立独立工作树，区分已有已发布代码、用户本地改动及私人数据。提交和推送前核对作者、提交者与共同作者署名。
2. 运行自动测试与 Edge 验收，新增可复现问题的最小回归。涉及桌宠或 SSP 时补对应真实运行检查。
3. 从干净提交打包，在 ZIP 实际条目和内容上核对空番库、默认设置、公开素材与校验清单。公开发行及 Git 提交排除本机番库、历史、账号配置和备份。
4. 在独立目录用上一公开便携版的数据副本迁移，并验证重启后的进度、记录、设置和开机自启。正式安装时先留恢复点，再验证用户当前安装。
5. 发布说明列出对应的改善、迁移路径和验收结果。出现个人数据损坏风险或关键路径失效时，暂停合并或发行并复测修复。
