# TIARA v0.43.0–v0.58.1 阶段检查

## 追番与本机数据

- Bangumi 同步可以逐条核对、按字段选择、取消和处理缓存回退。手填周档受保护。逐集记账支持跳集、回补、按周回顾和误删恢复。
- 开播与补番提醒有分日免打扰、提前量及可取消的稍后提醒。日历可单次导出或在本机订阅；只读看板可以独立开窗。
- 大番库首页复用计算。旧表格可离线预览导入，封面有本地缓存。升级向导可以搬运浏览器偏好，备份页面可以查范围和占用。

## 桌宠与陪伴

- 桌宠可记住各屏位置，支持召回、全屏临时隐身、气泡优先级及减弱动画。便条可搜索、恢复和提醒，专注计时记住上次时长。
- 手账可收藏台词、查看里程碑及元旦来信。托盘和立绘菜单可各自固定常用操作。离线猜数字、中文朗读和双角色对白均已实机检验。
- SSP 外观可预览底图、静态 PNG 叠层和矩形碰撞区。人格素材试验可以检查缺件、切换和恢复。公开 SSP 包和含个人排片的私人快照各有独立入口。

## 试验结论

单集 Bangumi 回写使用独立测试响应验证确认、权限和重试，未写入个人 Bangumi 账号。日历订阅试验使用本机客户端。跨设备交换试验验证本地文件的冲突合并和删除保留，建议先完成手动文件交换设计。复杂动画继续由 SSP 渲染。各试验入口和边界见 [待办与验收索引](BACKLOG.md)。

## 发行与实机验收

最终候选 v0.58.1 已生成 Windows 便携包、公开 SSP 包和 SHA-256 清单。196 项自动测试通过，v0.58.0 到 v0.58.1 的升级、无系统 Node.js 时启动和保存进度、SSP 实机载入及公开包内容检查均通过。v0.58.0 也验证了可从公开 v0.30.0 直接升级。GitHub Actions 流水线已编写，本轮进行了本机验证。见 [v0.58.0 验收记录](VALIDATION-v0.58.0.md) 与 [v0.58.1 验收记录](VALIDATION-v0.58.1.md)。

最后一项双屏待办已验收。125% 和 150% 两块实际屏幕通过位置保存、跨屏召回、重启、看板全屏和副屏停用后的回退测试。阶段待办现已全部完成。
