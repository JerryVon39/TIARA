# 桌宠体验改进计划

以 v0.67.2 为基线。先缩短桌宠与托盘的常用操作，再改善提醒和气泡，最后整理显示与换装。沿用现有的看番陪伴、提醒与互动机制。

## v0.68 · 菜单与记一话

当前桌宠右键同时展示排片、补番、提醒记录、网页面板、同步与诊断。托盘又提供一组入口。已有常用菜单和最近操作，但固定项与自定义项需要分别维护，记一话也只显示前八部。

- 桌宠右键与托盘共享排片、记一话、桌宠显示及召回的命令和名称。首屏固定常用操作，保留现有自定义项，合并重复入口。把同步、日志和重算数据移到「维护」。
- 记一话优先展示用户置顶和近期观看的番剧，保留「查看全部」入口。成功后显示番名与更新后的集数，并提供撤销。操作失败时保留原进度并显示结果。
- 菜单支持方向键和 Esc。保留 Windows 高对比度和小工作区下的可用性。
- 参考橘花的分组入口，把「换装与气泡」放在容易找到的地方。右键菜单和托盘统一「找回桌宠」的语义，在找回设置中提供位置重置，便于换装后从屏幕边缘找回立绘和气泡。
- 验收覆盖空番库、超过八部、既有自定义项，以及桌宠隐藏后从托盘召回。从任一菜单访问排片、记一话或召回最多两步。验证一次记一话只生成一条记录。

## v0.69 · 气泡、提醒与安静模式

- 提醒气泡突出番名、待看集数和提醒时间，把「去观看」「稍后」放到同一位置。播放地址缺失时进入番剧详情。
- 在桌宠和网页沿用同一套提醒状态，让用户看见当前静音、延后到何时，以及错过的提醒已进入哪里。整理台词、提醒与用户主动互动之间的气泡顺序。
- 参考橘花把动作和台词接在同一次互动里的做法，在 TIARA 现有「说句话」「摸摸头」「喝杯茶」事件上统一反馈。主动操作优先，提醒到达后排队，空闲台词排在最后。现有猜拳、猜数字和手账返回同一个陪伴分组。
- 验收覆盖跨午夜、睡眠唤醒、专注结束和重启恢复。检查提醒记录、延后时间和网页显示一致，重复唤醒或重启时只提醒一次。

## v0.70 · 显示、换装与表情

- 整理「显示与召回」「窗口层级」「桌宠尺寸」「换装与气泡」的入口。让位置、层级、尺寸和透明点击区更容易预览、调整与恢复。
- 外观页可逐个预览表情，应用或取消。将困倦、思考和害羞接入正式套装，沿用现有相应事件。害羞在本地原型通过熟悉阶段当天首次摸头触发，新版继续为旧套装提供微笑回退。
- 参考橘花「试衣间」和「表情秀」，在一个换装窗口里显示当前套装、预览套装和实际可用的表情。切换前预览，确认后应用。记录上一套供撤销。首张损坏时提示保留原外观，缺失次要表情时明确显示回退。
- 立绘用同一套坐标描述透明区域、头脸命中区和气泡位置。换装尽量保住脚底锚点。用 TIARA 现有高身形和三套橘花小画布对照测试，覆盖换装中开着气泡、靠屏幕边缘换装和缩放后点击。
- 为新套装制作与各表情兼容的嘴部图层，让说话时保留眼神。原型使用静态嘴型。同步验证 SSP 的 YAYA 表情映射和旧皮肤回退。
- 验收覆盖双屏拖放、125% 与 150% 缩放、主屏拔除后召回、重启后的外观恢复及已有自定义套装迁移。用实际 SSP 引擎验收随包套装。

## 试用与交付

困倦、思考可以用 v0.67.2 桌宠的本地试用套装查看。害羞已在采用独立表情槽的本机原型中验证。正式发布前依次核验显示效果、旧皮肤回退、桌宠设置迁移、便携包和 SSP 包。

### 橘花参考套装

本机试用选取 Taromati2Enh 的预设、长裙和独立 winter.zip 的冬装。其中预设与冬装画布为 278 × 336，长裙为 300 × 344。每套使用五张现成立绘，从对应 PNA 读取透明度，并带有原作的头、脸和手的矩形区域。试用仅包含静态主角立绘，现有 TIARA 的对话、提醒和互动逻辑照常驱动。素材留在本机缓存和安装目录，保留可确认的出处与署名。

### 可选的后续改进

1. **本地立绘管理。** 先支持从指定目录预检并导入 TIARA 套装和 SSP 的静态子集。优先支持零填充编号、PNG + PNA 和同名套装冲突检查。清楚显示暂不支持的动画与附属角色，损坏套装可以直接回到内置外观。用现有迁移预览提示缺失套装，允许用户备份和重新导入自己的外观。
2. **图层换装。** 先用 TIARA 自有素材做一套可组合的口型和表情。只有在整套切换、气泡定位和命中区通过验收后，再尝试可开关的配饰图层。参考包的动画、换装绑定和双角色布局可以作为兼容性研究样本。
3. **场景化帮助。** 把「桌宠不见了」「换装后气泡跑偏」「立绘缺图」写成可直接操作的排障入口。优先提供召回、位置重置、恢复内置套装和查看诊断。
