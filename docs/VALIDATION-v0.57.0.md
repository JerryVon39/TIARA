# v0.57.0 验收记录

项目检查通过，192 项自动测试全部通过。

- **看板。** 解压的便携版从不含系统 Node.js 的 PATH 启动。在 Edge 从设置打开独立只读窗口，连续显示至少一个完整的 30 秒刷新周期，排片变化后自动更新下一档。Esc 关闭看板并返回原面板。番库中的暂停和已看完项目不进入看板，接口拒绝 POST。实际跨屏摆放与不同缩放留在双屏验收。
- **设备交换。** 运行 `node tools/simulate_device_sync.mjs`。两份合成番库的七个操作序列化后为 933 字节。交换顺序和重复交换不改变结果。两端同时改同一首轮进度进入人工核对，排期等不同字段可独立合并；一端删除、一端离线编辑时条目继续隐藏，受影响的编辑可查阅。
- **身份和范围。** 试验用设备 ID、设备序号、已见版本向量识别因果关系。正式实现需要为每份安装生成随机设备 ID，复制来档时给新设备重新编号。首轮只评估标题、观看状态、已看进度和手填排期；令牌、浏览器设置及桌面资料由现有本机机制处理。历史撤销需要可跨设备引用的记录 ID，纳入同步前应继续设计。
- **方案比较。** 本地文件交换可用同一份 JSON 验证收敛和冲突，部署成本较低，需要用户主动传递文件。远程服务可以自动交换，还需要身份认证、权限管理、处理断线重试，并确定删除记录保留期。当前试验结果支持先做本地文件交换的产品设计。
- **发行。** 重新生成两种公开 ZIP 和 SHA-256 清单，核对通过。
